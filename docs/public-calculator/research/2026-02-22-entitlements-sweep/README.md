# Entitlements sweep (2026-02-22)

Goal: capture **“what you get, where you get it”** for subscriptions and developer tools, using **official sources** wherever possible.

This sweep focuses on:
- included surfaces (web/desktop/mobile/CLI/IDE/GitHub)
- provider/model coverage (only when explicitly documented)
- modality coverage (text/image/voice/video/etc) when explicitly documented
- any explicit numeric quotas or plan limits

Notes:
- This repo’s backend treats entitlements as **feature flags with evidence**. If data is unknown, we keep it computable (fee floor) and label confidence as low.
- We attempted to spawn multiple research agents, but agent spawning is currently blocked by a thread limit; findings are still written as separate “agent-*” notes for traceability.
