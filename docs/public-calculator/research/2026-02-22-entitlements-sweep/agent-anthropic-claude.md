## Findings (official, retrieved 2026-02-22)

From `https://claude.com/pricing`:
- **Pro**: $20/mo billed monthly (or $200 billed annually; “$17 per month with annual discount”). Includes “More usage”, Claude Code, Projects, Research, Memory, and “ability to use more Claude models”.
- **Max**: “From $100 per person billed monthly” and advertises “Choose 5x or 20x more usage than Pro” plus priority access and higher output limits.
- The pricing page also enumerates product surfaces and capabilities that are useful as entitlements, including:
  - Claude apps: web, iOS, Android, desktop
  - Claude Code “everywhere (terminal, web, desktop)”
  - Voice mode, projects, connectors/remote MCP, research, memory, etc.

From `https://claude.com/pricing/max`:
- The Max plan page reinforces that Max bundles Claude apps + Claude Code and describes “up to 20x more usage per session than Pro”.
