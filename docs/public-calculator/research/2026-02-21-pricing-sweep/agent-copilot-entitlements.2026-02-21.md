# GitHub Copilot — entitlements (what’s included, where) (snapshot)

**retrieved_at:** 2026-02-21  
**last_verified_at:** 2026-02-21

## Scope

This note captures what GitHub documents as included with Copilot plans, focusing on **feature availability** and **surfaces** (IDE, GitHub.com, mobile, etc.). Premium request counts and pricing are tracked in the pricing sweep note; this file is about “what you get”.

## Plan lineup (official)

GitHub documents plans for individuals (Free/Pro/Pro+) and for orgs/enterprises (Business/Enterprise), with plan-specific feature availability.

## Surfaces (where Copilot features appear)

GitHub documents Copilot features across:
- IDEs (VS Code, JetBrains, Visual Studio, Xcode)
- GitHub.com
- GitHub Mobile

## PR/code review surfaces (official)

GitHub documents “Copilot code review” availability across:
- JetBrains IDEs
- Xcode
- Visual Studio
- VS Code
- GitHub Mobile
- GitHub.com

and states that Copilot code review is available with:
- Copilot Enterprise
- Copilot Business
- Copilot Pro+
- Copilot Pro

## Agents / “coding agent” (official)

GitHub’s Copilot documentation distinguishes “Copilot coding agent” as a feature included in certain plan tiers (notably Business/Enterprise) and describes how to review PRs created by the coding agent.
