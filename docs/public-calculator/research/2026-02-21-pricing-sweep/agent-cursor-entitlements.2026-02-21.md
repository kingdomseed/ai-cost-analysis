# Cursor — entitlements (what’s included, where) (snapshot)

**retrieved_at:** 2026-02-21  
**last_verified_at:** 2026-02-21

## Scope

This note captures Cursor feature surfaces that matter for comparing “what you get” beyond token pricing (e.g., code review features, background agents, team analytics). It does **not** attempt to infer token costs; those are handled by Cursor’s plan pricing docs and model pricing tables.

## Primary surfaces

- Cursor editor (desktop IDE experience; Chat/Composer/Agent inside the editor)
- GitHub PR surface (Bugbot posts PR comments; “Fix in Cursor” workflow)
- Team admin/analytics surfaces (enterprise teams)

## Key entitlements / features (official)

- **Composer**: documented as a first-class feature surface in Cursor docs.
- **Bugbot (code review)**: documented as a PR review feature that comments on GitHub PRs, with a “Fix in Cursor” flow.
- **Background Agent**: Cursor changelog indicates expansion of Background Agent access (feature exists as a surface; plan gating may vary).
- **Enterprise team analytics export**: Cursor publishes an Analytics API for enterprise teams (usage metrics export surface).
