# Windsurf — entitlements (what’s included, where) (snapshot)

**retrieved_at:** 2026-02-21  
**last_verified_at:** 2026-02-21

## Scope

This note captures Windsurf “what you get” surfaces and features (beyond prompt credits), so we can compare Windsurf against other tools like Cursor and Copilot using a structured approach.

## Primary surfaces

- **Editor** features (Autocomplete, DeepWiki, etc.)
- **Cascade** agent features (workflows, MCP, rules/skills)
- **Teams/Enterprise** admin surfaces (team management, SSO, analytics)
- **GitHub integration** for PR Reviews (Teams/Enterprise)

## Key entitlements / features (official)

- **DeepWiki (code explanations):** editor feature for symbol-level explanations in a codebase.
- **Teams/Enterprise org features:** docs describe team management, SSO, analytics, groups, and priority support.
- **PR Reviews:** GitHub integration described as available for Teams and Enterprise (beta); posts review comments on GitHub PRs and supports slash commands.

## Credit vs feature separation

Windsurf uses **prompt credits** for access to premium models in Cascade, but some features are not simply “credits”:
- PR Reviews are a separate GitHub integration surface with its own operational constraints.
- Teams features include org/admin functionality that is not a token-meter comparison.
